# Deployment

LockLens requires two separate PostgreSQL databases or database endpoints: metadata (`DATABASE_URL`) and the isolated experiment lab (`LAB_DATABASE_URL`). The lab connection is intentionally destructive within schema `lab`; never give it metadata-database credentials.

## Render

`render.yaml` defines a Docker API service and a React static site. Push this folder to a GitHub repository, then create a Render Blueprint from that repository. Before deploying, set the following secret values in Render:

| Variable | API service value |
| --- | --- |
| `DATABASE_URL` | Render PostgreSQL connection URL for metadata, in SQLAlchemy `postgresql+psycopg://` form |
| `LAB_DATABASE_URL` | PostgreSQL URL for the isolated lab database, using the least-privilege lab role |
| `CORS_ORIGINS` | Exact static-site URL, for example `https://locklens-web.onrender.com` |
| `JWT_SECRET` | Generated by the Blueprint; replace it only through Render secrets if required |

Set `VITE_API_BASE_URL` on the static site to the public API URL, e.g. `https://locklens-api.onrender.com`. It is a build-time value, so redeploy the static site after changing it.

Provision the lab database and role with the equivalent of `db/init/01_lab.sql`, supplying `LAB_PASSWORD` securely. Render's managed PostgreSQL creation flow does not automatically run this repository's Docker init script, and may not permit creation of a second database under the supplied user. Use a PostgreSQL service/account where an administrator can create the isolated database and role first.

The API container runs `alembic upgrade head` before Uvicorn, listens on Render's `PORT`, and exposes `/api/health`. Check `/api/ready` after deployment; it verifies both database connections. Roll back by redeploying the prior successful Render deploy after taking a metadata database backup.

## GitHub readiness

Initialize and publish the repository from the project root:

```powershell
git init
git add .
git commit -m "Prepare LockLens for deployment"
git branch -M main
git remote add origin https://github.com/OWNER/locklens.git
git push -u origin main
```

The included GitHub Actions workflow builds the frontend and runs backend tests against PostgreSQL 17. Review the workflow before enabling it, because browser tests require the backend database variables to be valid in the job.
